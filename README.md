# Задание №1: Калькулятор

В данной ветке было реализовано практическое задание №1 - Калькулятор.

### Реализованные ограничения

1. Запрет деления (и выполнения некоторых других операций) на 0;
2. Ограничение количества выдаваемых символов после знака запятой;
3. Запрет на извлечение корня из отрицательных чисел;
4. Проверка вводимых чисел пользователем;

Так же была реализована работа с выводом при помощи паттернов ООП.
